# Release Notes - Version 2.0.0 (Build 58)

## What's New in This Version

### 🎨 All-New Look and Feel

- **Redesigned App-Wide**: Every screen now runs on BPVA's new design system, with consistent colors, status indicators, and spacing
- **Refreshed Navigation**: Cleaner menu hub for Athletes, Content, and Setup sections
- **Theme-Aware Everywhere**: Environment badges and UI colors adapt properly in both light and dark mode

### 🏋️ Pole Rental Requests

- **Request From Inventory**: Athletes and parents can request a pole rental directly from the pole inventory screen
- **Parents Can Submit for Athletes**: Parents can request a rental on behalf of a linked athlete
- **Coach & Admin Review**: A dedicated Requests view lets coaches and admins approve and track pending rentals

### 📝 Front-Desk Registration for Walk-In Athletes

- **Receptionist Paperwork**: Front-desk staff can now complete registration and waiver forms for athletes who check in without the app
- **Form Status Tracking**: See at a glance whether an athlete's paperwork is complete
- **Automatic Recovery**: Documents regenerate automatically if an upload is interrupted partway through

### 📴 Offline Session Logging

- **Log Sessions Without Internet**: Manually back-date a drop-in athlete's check-in when connectivity isn't available

### 🖨️ Brother Printer Improvements

- **Custom Printer Plugin**: Switched to a purpose-built Brother printer integration for more reliable pole inventory label printing on both iOS and Android

### 🛠️ Admin Tools

- **Smarter Duplicate Detection**: Catches duplicate accounts even when a profile is incomplete or unnamed
- **Merge Screen Search**: Filter and search the duplicate-user merge screen
- **Merge Audit Trail**: Review a history of past account merges

### 🐛 Bug Fixes

- Fixed the "Enable Ads" setting not actually disabling ads when turned off
- Fixed the loading screen video being capped too small on tablets and large landscape screens
- Fixed a build issue that could leave the project in the wrong directory after a failed dependency install

---

This release marks **BPVA Calendar 2.0** — a redesigned app with pole rental requests, faster front-desk check-in for walk-in athletes, and a more polished experience across the board.
